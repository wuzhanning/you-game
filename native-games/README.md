# YouGame 原生迷你街机

面向 Android 9 / 2GB 内存电视的六款**非棋盘**动作游戏。使用 Java、原生 Canvas 和 SoundPool，支持电视遥控器，完全离线，无广告，无第三方游戏引擎。大厅仍保留原有星球碰碰乐的 WebView 入口。

## 六种玩法

| 游戏 | 核心决策 | 遥控器 | 通关目标 |
| --- | --- | --- | --- |
| 数字弹射 | 直射、借墙反弹、换弹，打出接触连锁 | 左右瞄准；确认发射；上换弹 | 合成 32，逐步提高到 256；每四发球群下降，90 秒限制 |
| 叠塔工坊 | 把握落点；偏差切边，完美落点修复塔宽 | 确认落塔；左右微调 | 成功落塔 12–20 次；同数字及相邻下层可连锁翻倍 |
| 数字疾跑 | 换道避障、跳栏、滑过横梁，选择运算门 | 左右换道；上 / 确认跳；下滑行 | 跑完 420 米，数字足够击破终点墙 |
| 运算竞技场 | 收集小数字，抢 +8 / ×2 运算环，绕柱追逐 | 方向键持续移动；确认冲刺 | 在 80 秒内连续击败三个 AI 对手 |
| 红蓝吞噬 | 连续空间中追小避大，选择成长路线与撤离时机 | 方向键持续移动；确认冲刺 | 达到目标数字并到东侧传送门撤离，100 秒限制 |
| 企鹅冰原 | 冰坡滑行、二段跳跨冰缝，收集空中鱼群 | 确认 / 上二段跳；左刹车，右加速；按住下低身滑行 | 带够数字小鱼抵达营地；星星跨关积累以改变配色 |

进入游戏后先显示准备画面，确认出发。返回、菜单或手柄 Start 可暂停，暂停菜单支持继续、玩法说明、重玩、回大厅、开关音效。暂停和切后台会移除帧回调、清除按住的方向键；恢复应用后需要确认继续。

每款游戏有独立局面、解锁进度、最高分和逐关星级评价，最多 60 关。成功后解锁下一关，也可选择已经解锁的关卡重玩。跑酷和企鹅使用可学习的固定场景段落，随关卡提升速度、缺口或目标；竞技场与吞噬场的收集物提供变化。数字封顶 99999。

## 设计依据

最初的《数字合成游戏合集方案》提供了数字成长主题；按后续要求，六款全部重做为非棋盘玩法。

参考成熟游戏的设计原则，而非复制它们的素材或代码：

- [Number Master（KAYAC）](https://www.kayac.com/service/game/1890)：数字成长与可预读的路线决策。本作采用三跑道、明确的运算门、终点数字要求。
- [Subway Surfers 官方操作说明](https://sybo.helpshift.com/hc/en/5-subway-surfers/faq/205-basics/?p=all)：换道、跳跃、滑行对应不同障碍。本作分别实现矮栏、高横梁和不可跳过的实心路障。
- [Agar.io 官方指南](https://support.miniclip.com/hc/en-us/articles/4404685562641-How-to-start-playing-Agar-io)：连续空间中的成长、追逐、撤退与位置选择。本作使用本地 AI、运算环或撤离目标，不包含联网对战。

场景、角色、伪透视几何、数字球、高塔和企鹅均由原生矢量绘制。五种短音效为程序合成的原创 WAV，可在暂停菜单关闭。轻量粒子池、数字浮字、连击、危险提示和独立场景反馈用于帮助判断操作结果。

## 存档与覆盖安装

新街机版使用 `native-arcade-v2` SharedPreferences，包含版本 2 二进制局面与 CRC32 校验。旧棋盘实验版 `native-games-v1` 数据保留，但玩法完全不同，不将它的局面转换进新游戏。星球游戏的 WebView 存档不受影响。

每 5 秒保存检查点，暂停、切换、离开时立即保存；突然断电可能丢失最近一个检查点后的进度。覆盖安装保留数据，卸载或清除应用数据会删除存档。签名沿用 `android-tv/.debug.keystore`，密钥不进入 Git。

## 源码与性能

`src/com/wuzhanning/yougame/nativegames/`：

- `Game.java`：Android 无关的连续坐标规则。固定 96 个对象、48 个特效槽；60 Hz 固定步长处理碰撞与动作，限制长时间卡顿后的追帧量。
- `GameView.java`：一个硬件加速 Canvas。使用 Choreographer 跟随屏幕刷新，在 60 Hz 屏幕上隔帧绘制，目标 30fps；复用 Paint / Path、渐变与数字标签，准备、暂停、后台不持续调度。
- `NativeActivity.java`：原生焦点、大厅、关卡、帮助、结果、音效和生命周期存档。
- `assets/sounds/`：短音效，构建时和原有 H5 资源一起打包，彼此独立。

在这个子目录添加后续游戏即可；构建脚本自动收集 Java 文件。目前不引入插件系统、外部引擎或网络服务。

```sh
python3 native-games/check.py
node planet-game/check.cjs
node --check planet-game/dist/game.js
node --check planet-game/dist/tv.js
python3 android-tv/build.py
```

[检查程序](test/com/wuzhanning/yougame/nativegames/GameCheck.java) 使用 JDK 与标准库，覆盖弹射反弹与连锁、高塔切边与连锁、跑酷动作判定、对战与吞噬、企鹅二段跳与冰缝、容量上限、存档损坏及多难度模拟。跑酷和企鹅还使用规则驱动的操作序列验证第 1、10、30、60 关存在可完成路线。

安装包：[YouGame-TV-debug.apk](../android-tv/releases/YouGame-TV-debug.apk)。设备与性能验证见 [QA.md](QA.md)。
