# 星球碰碰乐

儿童友好的 H5 星球合成游戏。原生 HTML、CSS 和 Canvas，无外部依赖。

## 运行

直接打开 `dist/index.html`，或在本目录运行：

```sh
python3 -m http.server 5173 --directory dist
```

浏览器访问 http://localhost:5173 。手机可使用部署后的网址。

移动鼠标或拖动手指选位置，松开投放。左右方向键移动，空格或回车投放。相同星球碰撞后升级，堆过星光线持续约 2.5 秒结束。支持暂停、可选音效、重新开始与设备本地最高分。离开页面自动暂停。

成长图鉴为游戏想象，不代表真实星球大小。无广告、无付费、无倒计时。

## 检查

```sh
node check.cjs
node --check dist/game.js
```

物理检查覆盖相同星球合成、不同星球碰撞、最高等级、边界约束与密集场景。

## 手柄

使用浏览器标准 Gamepad 映射，无额外依赖。左摇杆或十字键左右移动；下方主按键（Xbox A / PlayStation ×）投放；Start / Options 暂停。暂停或结束后主按键继续或重开。弹窗内十字键选按钮、主按键确认、B / ○ 返回。

打开页面后先点击页面，再按一下手柄按键；游戏下方会显示连接状态。摇杆有 20% 死区；按键每次按下只触发一次；断连或窗口失焦自动暂停。非标准映射会显示提示，避免错认按键。优先通过 localhost 运行，若浏览器未暴露手柄则不会显示已连接。真实手柄按键仍需在设备浏览器中实测。

## 音效、全屏与存档

默认铺满浏览器页面，点击“全屏”进入系统全屏，再点可退出；不支持 Fullscreen API 的浏览器保持页面铺满布局并提示。移动端横竖屏均适配。

音效默认开启：投放、合成、重开和结束有不同音色序列；首次点击页面或键盘输入后解锁声音，♫ 可静音并记住设置。只使用手柄时，请先轻点页面，让浏览器允许声音播放。

当前分数、最高分、星球位置、下一颗星球和图鉴会自动存入当前浏览器的 localStorage。投放、合成、暂停、重开和离开时保存，游戏中每秒补存一次。刷新后暂停等待继续；重新开始只清空当前局，保留最高分。存档仅在当前设备、浏览器及同一网址来源内有效，清除站点数据会删除存档；不提供跨设备同步。存储失败时页面会提示。

## 炸弹与最终星球

每次合成一个木星获得 1 颗炸弹，可累积并随当前局存档保存。点击 💣 后点击目标，消除一个指定星球；不会增加或扣除分数。选择期间物理模拟暂停，点空白、取消都不消耗。键盘 B / 手柄 B（○）开启或取消，方向键循环选目标，空格或回车 / 手柄 A（×）确认。暂停或断连会取消选择；重开清空当前局炸弹。旧存档正常读取，初始炸弹数为 0。

合成链共 11 级：水星 → 火星 → 金星 → 海王星 → 地球 → 天王星 → 土星 → 木星 → 太阳 → 红巨星 → 黑洞。相同太阳合成红巨星，相同红巨星合成黑洞，黑洞不再升级。金星采用云纹，太阳带金色光芒，红巨星为红色光芒，黑洞为暗色核心和吸积环。
